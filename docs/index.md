# gld-ion-kotlin

gld-ion-kotlin is an [Amazon Ion](https://amazon-ion.github.io/ion-docs/)
serializer written in Kotlin. The runtime and the code generator are Kotlin.
They do not wrap ion-java or any other Ion library.
